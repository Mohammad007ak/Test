# بروشور محصولات دیجی‌پی برای مشتریان بانک تجارت

سند معرفی محصولات، خدمات و ظرفیت‌های دیجی‌پی برای مدیران مناطق و شبکه شعب بانک تجارت (پاسخ به نامه تکنوتجارت، مهلت ۱۵ مهر ۱۴۰۵).

- خروجی نهایی: `dist/digipay-tejarat-brochure.pdf` (A4 افقی، ۳۹ صفحه، ۱۴ محصول به تفکیک بانکداری شخصی، تجاری، شرکتی و اصناف)
- متن‌ها: `src/content.mjs` (همه محتوا اینجاست؛ برای ویرایش متن فقط همین فایل را تغییر دهید)
- استایل: `src/styles.css` (رنگ‌ها و تایپوگرافی برگرفته از کاتالوگ «راهکارهای سازمانی دیجی‌پی»)
- ساخت: `node build.mjs` (نیازمند Playwright و Chromium)؛ `node build.mjs --png` پیش‌نمایش PNG هم می‌سازد.

فونت‌ها: Vazirmatn (OFL) و Outfit (OFL) به‌عنوان جایگزین YekanBakh و Gilroy. در صورت داشتن لایسنس YekanBakh، کافی است `@font-face`های `src/styles.css` را به آن تغییر دهید.
آیکون‌ها: Lucide (ISC).
