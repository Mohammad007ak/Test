# دستیار مالی هوشمند — MVP

ترازنامه شخصی تک‌کاربره (فاز صفر). مرجع محصول: [`SPEC.md`](SPEC.md) · قواعد کد: [`CLAUDE.md`](CLAUDE.md)

## اجرا

```bash
uv sync                      # Python 3.12 و وابستگی‌ها
uv run uvicorn app.asgi:app  # http://127.0.0.1:8000
```

در اولین باز کردن، رمز عبور را تعیین می‌کنی. دیتابیس در `data/finassist.db` ساخته می‌شود و مایگریشن‌ها هنگام شروع خودکار اجرا می‌شوند.
برای باز کردن روی گوشی در همان شبکه: `--host 0.0.0.0` و سپس آدرس لپ‌تاپ؛ از Safari «Add to Home Screen».

## اجرا روی سرور (کوبرنتیز هم‌روش یا هر سرویس داکری)

`Dockerfile` آماده است. برنامه روی پورت `8000` بالا می‌آید و دیتابیس در `/app/data` است.

- **فقط یک نسخه (replica: 1).** SQLite و زمان‌بند قیمت داخل همان پردازه‌اند.
- **دیسک ماندگار روی `/app/data`.** وگرنه با هر استقرار اطلاعات پاک می‌شود.
- **متغیرهای محیطی (به‌صورت secret):**
  - `FINASSIST_SECRET_KEY`: یک رشته تصادفی بلند.
  - `FINASSIST_SETUP_CODE`: کدی که برای گذاشتن اولین رمز لازم است، تا کسی زودتر از تو رمز نگذارد.
- **HTTPS را سرویس می‌دهد.** کوکی‌ها در ایمیج به‌صورت پیش‌فرض Secure هستند.
- اگر وابستگی‌ها عوض شد، `requirements.txt` را دوباره بساز:
  ```bash
  uv export --no-dev --no-hashes --no-emit-project --format requirements-txt -o requirements.txt
  ```

ورود بعد از ۵ رمز اشتباه از یک آدرس، ۱۵ دقیقه بسته می‌شود.
