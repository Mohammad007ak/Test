# صندوقچه 🪙

مدیریت ساده و شفاف **صندوق قرض‌الحسنه‌ی خانوادگی و دوستانه**.

صندوقچه پول را جابه‌جا نمی‌کند. پول همیشه در حساب بانکی مدیر صندوق می‌ماند و اپ فقط ثبت می‌کند چه کسی پرداخت کرده، چه کسی بدهکار است و وام به چه کسی رسیده.

## امکانات (نسخه‌ی اولیه)

- **تعریف صندوق:** سهم ماهانه، مبلغ وام، تعداد اقساط و ماه شروع (تقویم شمسی)
- **اعضا:** نام، موبایل، تعداد سهم و ماه عضویت
- **پرداخت‌ها:** ثبت سهم ماهانه و قسط وام هر عضو با یک کلیک، برای هر ماه
- **قرعه‌کشی:** قرعه‌کشی انیمیشنی و شفاف (هر سهم یک شانس)، کنترل موجودی صندوق و دورهای قرعه‌کشی
- **وام‌ها:** پیشرفت بازپرداخت هر وام و مبلغ مانده
- **داشبورد:** موجودی صندوق، وصولی این ماه، فهرست بدهکارها و **پیامک یادآوری**
- **پشتیبان‌گیری:** دانلود و بازیابی فایل JSON

اطلاعات فعلاً فقط در مرورگر همان دستگاه ذخیره می‌شود.

## اجرا

به [Node.js](https://nodejs.org) نسخه‌ی ۲۰ یا بالاتر نیاز دارید.

```bash
npm install
npm run dev
```

بعد آدرس `http://localhost:5173` را در مرورگر باز کنید. برای دیدن سریع امکانات، در صفحه‌ی اول روی «دیدن نمونه با اطلاعات آزمایشی» بزنید.

| دستور | کار |
|---|---|
| `npm run dev` | اجرای نسخه‌ی توسعه |
| `npm test` | اجرای تست‌های منطق صندوق |
| `npm run build` | ساخت نسخه‌ی نهایی در پوشه‌ی `dist` |

## ساختار کد

```
src/
  lib/          منطق خالص (بدون رابط کاربری)
    fund.js       محاسبه‌ی بدهی‌ها، موجودی، اقساط و قرعه‌کشی
    jalali.js     تبدیل و محاسبه‌ی ماه‌های شمسی
    fund.test.js  تست‌ها
  components/   صفحه‌های اپ
```
