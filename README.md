# دستیار مالی هوشمند — MVP

ترازنامه شخصی تک‌کاربره (فاز صفر). مرجع محصول: [`SPEC.md`](SPEC.md) · قواعد کد: [`CLAUDE.md`](CLAUDE.md)

## اجرا

```bash
uv sync                      # Python 3.12 و وابستگی‌ها
uv run uvicorn app.asgi:app  # http://127.0.0.1:8000
```

در اولین باز کردن، رمز عبور را تعیین می‌کنی. دیتابیس در `data/finassist.db` ساخته می‌شود و مایگریشن‌ها هنگام شروع خودکار اجرا می‌شوند.
برای باز کردن روی گوشی در همان شبکه: `--host 0.0.0.0` و سپس آدرس لپ‌تاپ؛ از Safari «Add to Home Screen».

## تست و لینت

```bash
uv run pytest
uv run ruff check .
```
