# صندوقچه 🪙

مدیریت ساده و شفاف **صندوق قرض‌الحسنه‌ی خانوادگی و دوستانه**.

صندوقچه پول را جابه‌جا نمی‌کند. پول همیشه در حساب بانکی مدیر صندوق می‌ماند و اپ فقط ثبت می‌کند چه کسی پرداخت کرده، چه کسی بدهکار است و وام به چه کسی رسیده.

## امکانات

- **ورود با کد پیامکی:** بدون رمز عبور، فقط با شماره موبایل
- **مدیر صندوق:** تعریف صندوق، اعضا، ثبت سهم ماهانه و اقساط، داشبورد بدهکارها و پیامک یادآوری
- **قرعه‌کشی شفاف روی سرور:** برنده روی سرور با عدد تصادفی امن انتخاب می‌شود و **هر قرعه، حتی قرعه‌های لغوشده، ثبت می‌شود**. پس مدیر نمی‌تواند آن‌قدر قرعه بکشد تا نفر دلخواهش برنده شود.
- **صفحه‌ی عضو:** هر عضوی که شماره‌اش در صندوق ثبت شده، با همان شماره وارد می‌شود و وضعیت پرداخت‌ها، وامش، موجودی صندوق و سابقه‌ی همه‌ی قرعه‌ها و وام‌ها را می‌بیند.
- **پشتیبان‌گیری:** دانلود و بازیابی فایل JSON

## اجرا روی کامپیوتر خودتان

به [Node.js](https://nodejs.org) نسخه‌ی ۲۲٫۱۳ یا بالاتر نیاز دارید. دیتابیس (SQLite) داخل خود Node است و نصب جداگانه نمی‌خواهد.

```bash
npm install
npm run dev
```

بعد آدرس `http://localhost:5173` را باز کنید. در حالت توسعه پیامک واقعی فرستاده نمی‌شود و **کد ورود روی صفحه نشان داده می‌شود**.

برای دیدن نمای عضو: یک صندوق بسازید، عضوی با شماره‌ی دیگری اضافه کنید، خارج شوید و با آن شماره وارد شوید. (صندوق نمونه‌ی آزمایشی شماره‌های ساختگی دارد و برای اعضا نمایش داده نمی‌شود.)

| دستور | کار |
|---|---|
| `npm run dev` | اجرای نسخه‌ی توسعه (سایت و API روی یک پورت) |
| `npm test` | اجرای تست‌ها |
| `npm run build` | ساخت نسخه‌ی نهایی در پوشه‌ی `dist` |
| `npm start` | اجرای نسخه‌ی نهایی روی سرور |

## اجرا روی سرور

```bash
cp .env.example .env   # کلید کاوه‌نگار را وارد کنید
npm install
npm run build
npm start
```

- برای ارسال کد ورود یک حساب [کاوه‌نگار](https://kavenegar.com) و یک قالب «اعتبارسنجی» (verify lookup) لازم است که متنش `%token%` داشته باشد.
- پشت یک reverse proxy با **HTTPS** اجرا کنید (مثلاً Nginx یا Caddy). کوکی ورود در حالت production فقط روی HTTPS فرستاده می‌شود.
- اطلاعات در فایل `data/sandogh.db` ذخیره می‌شود. از آن به‌طور منظم پشتیبان بگیرید.

## ساختار کد

```
server/         API (Express + SQLite داخلی Node)
  app.js          ورود، صندوق‌ها، قرعه‌کشی و نمای عضو
  db.js           جدول‌های دیتابیس
  app.test.js     تست‌های API
src/
  lib/          منطق خالص که هم مرورگر و هم سرور از آن استفاده می‌کنند
    fund.js       محاسبه‌ی بدهی‌ها، موجودی، اقساط و قرعه‌کشی
    jalali.js     تبدیل و محاسبه‌ی ماه‌های شمسی (به وقت تهران)
  components/   صفحه‌های اپ
```
